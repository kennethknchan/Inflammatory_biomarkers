# The interplay of biomarkers of systemic and local coronary inflammation in cardiovascular risk prediction.

## Repository for IMC analysis

This project is based on an adapted version of the SpOOx (Spatial Omics Oxford) analysis pipeline, originally developed by the Taylor CCB Group at the University of Oxford.

The original pipeline was developed for processing and analysing spatial proteomics data, including image processing, cell segmentation, clustering, and spatial statistical analysis.

**https://github.com/Taylor-CCB-Group/SpOOx**

For detailed documentation, installation instructions, and pipeline usage, please refer to the original repository.

Modifications: The original pipeline has been adapted for the requirements of our project, with modifications to the analysis workflow and additional R scripts for project-specific analyses.

Acknowledgement: We acknowledge the original SpOOx developers and contributors. This repository builds upon their work, with adaptations made for our specific research purposes.

## time ROC analysis
 Description:
 Fits Cox proportional hazards models and evaluates their
 discrimination using time-dependent ROC curves and AUC.

## Transcriptomic analysis 
Description: 
A modular R workflow for differential gene expression and pathway-level analysis of bulk RNA sequencing data.
RNA-seq quality checks, filtering, normalization, differential expression testing, over-representation analysis, ranked gene set enrichment analysis, and Gene Set Variation Analysis
